
每个目录一个包,一般包名和目录名称保持一致, main 包包含可执行入口,有 main 函数

为结构定义的方法必须放在同一个包内,可以是不同文件

在包级别声明的变量会在main入口函数执行前完成初始化

局部变量将在声明语句被执行到的时候完成初始化。

```go
var i, j, k int                 // int, int, int
var b, f, s = true, 2.3, "four" // bool, float64, string

```

简短变量声明
+ 只能在函数内部
+ 也支持声明和初始化一组变量
```go
i, j := 0, 1
```

```go
i, j := 1, 2

x, j := 3, 5 // 这里的 j 会被覆盖

```


对于每一个变量必然有对应的内存地址。通过指针，我们可以直接读或更新对应变量的值，而不需要知道该变量的名字（如果变量有名字的话）。


元组赋值是另一种形式的赋值语句，它允许同时更新多个变量的值。在赋值之前，赋值语句右边的所有表达式将会先进行求值，然后再统一更新左边对应变量的值。

```go
x, y = y, x
a[i], a[j] = a[j], a[i]

```

## init 函数

`func init()` 是特殊函数，不能有参数和返回值，也不能被显式调用，而是在程序运行时自动执行。

执行时机：包级别变量初始化完成之后 → `init()` 执行 → `main()` 执行前。

一个文件甚至一个包中可以定义多个 `init`，按声明顺序（跨文件按文件名顺序）依次执行。

```go
func init() {
	// 初始化只能通过声明语句完成的包级变量
	// 或在程序真正开始执行前进行状态检查、注册等操作
}
```

如果包之间存在依赖，会先完成被依赖包的变量初始化和 `init`，再执行当前包的。

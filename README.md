# go-learning

跟随《The Go Programming Language》(gopl) 学习 Go 语言的练习代码。

## 参考资料

- [Go 圣经中文版](https://gopl-zh.github.io/index.html)
- [原书示例代码 gopl.io](https://github.com/adonovan/gopl.io)

## 目录结构

- `ch1/` — 第一章练习
  - `helloworld/` — Hello, World
  - `echo1` / `echo2` / `echo3` — 命令行参数回显的三种实现
  - `dup1` / `dup2` / `dup3` — 查找重复行的三种实现

## 运行

```bash
go run ./ch1/helloworld
```

# 学习笔记

## 切片字面量 `[]int{...}` 和数组字面量 `[3]int{...}` 的区别

`arr2 := []int{1, 3, 5}` 和 `arr2 := [3]int{1, 3, 5}` **不是一回事**，前者是切片（slice），后者是数组（array），两者是不同的类型。

| | `[]int{...}`（切片） | `[3]int{...}`（数组） |
|---|---|---|
| 类型 | `[]int`，长度不是类型的一部分 | `[3]int`，长度是类型的一部分 |
| 长度 | 可变，底层可扩容（`append`） | 固定为 3，不可变 |
| 赋值/传参 | 传递的是指向底层数组的引用（含 len/cap），共享底层数据 | 值拷贝，传参会复制整个数组 |
| 底层实现 | 是对数组的一层封装（指针+长度+容量） | 是最原始的定长内存块 |

值语义 vs 引用语义的区别示例：

```go
a := [3]int{1, 3, 5}
b := a          // 拷贝整个数组
b[0] = 100
fmt.Println(a)  // [1 3 5]，不受影响

s := []int{1, 3, 5}
t := s          // 拷贝的是切片头，底层数组还是同一个
t[0] = 100
fmt.Println(s)  // [100 3 5]，会被改变
```

日常写 Go 代码时切片用得远比数组多，因为更灵活（可以 `append`）；数组主要用在需要固定大小、追求性能或值语义的场景，例如 `arrays.go` 里 `printArr(arr [5]int)` 通过值拷贝传参、`grid [4][5]int` 这种固定形状的多维结构。

参考代码位置：`flowup/arrays/arrays.go:9,29-32`

## 指针访问数组/结构体时不需要手动解引用

`func modifyArr(arr *[5]int) { arr[0] = 100 }` 里 `arr` 是 `*[5]int`（指向数组的指针），但可以直接写 `arr[0]`，不需要写成 `(*arr)[0]`。

Go 对指向数组（或结构体）的指针做了语法糖：**可以直接用 `[]` 或 `.` 访问，编译器会自动解引用**，即：

```go
arr[0] = 100
// 等价于
(*arr)[0] = 100
```

结构体指针访问字段同理：

```go
type Point struct{ X int }
p := &Point{X: 1}
p.X = 100   // 等价于 (*p).X = 100
```

因为 `modifyArr` 传的是指针，函数内部的修改会影响调用者传入的原数组，这与值传递的 `printArr(arr [5]int)`（拷贝，不影响外部）形成对比。

参考代码位置：`flowup/arrays/arrays.go:42-46`

从切片中删除元素

```go
s1 = append(s1[:3], s1[4:]...)
```

+ `s1[:3]` 取出被删除元素（下标 3）之前的所有元素
+ `s1[4:]` 取出被删除元素之后的所有元素
+ `...` 展开操作符，把切片元素逐个作为变长参数传给 `append`，而不是整体作为一个切片传入
+ `append` 把删除点之后的元素依次追加到删除点之前的元素末尾，从而覆盖原下标 3 的位置，实现"删除"

一般化写法，删除下标 `i` 的元素：

```go
s = append(s[:i], s[i+1:]...)
```

注意：`append` 是在 `s1[:3]` 的底层数组上原地写入的（只要容量够不会重新分配），所以删除后 `len(s1)` 减 1，但 `cap(s1)` 不变，因为底层数组还是同一个。
